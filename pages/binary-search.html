Binary Search

Under the hood

How it works

01

Description

Enter a value and follow binary search through a sorted array of 29 unique values.

02

Logic used

The sketch compares the target with the middle value, then discards the half that cannot contain it. It repeats the comparison until the value is found or the range is empty.

03

Functions used

bbox( ) - to display each element of the array with different dimension,color and position

bsearch( ) - to perform the binary search algorithm and call bbox based on position and color
