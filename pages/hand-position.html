Under the hood

How it works

01

Description

Visualise detected hand landmarks as the hand moves in front of the camera.

02

Logic used

The ml5 Handpose model reports landmark coordinates for the visible hand. The sketch uses those coordinates to size ellipses in the visualisation.

03

Functions used

handpose( ) - ml5 library to access hand gesture positions in realtime

ellipse( ) - to draw circles based on the handposition values
