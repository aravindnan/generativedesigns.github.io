Under the hood

How it works

01

Description

A monochrome radial pattern visualises 360 values sampled from a Gaussian distribution. Generate new samples in place by clicking the canvas or the New pattern button; each pattern grows outward as it animates.

02

Logic used

Each Gaussian random sample sets a spoke length around the canvas centre. The spokes slowly expand to the canvas edge and contract in a repeating cycle. Generating a pattern replaces the samples without reloading the page.

03

Functions used

drawPattern( ) - to display the vectors moving or expanding

randomGaussian( ) - to calculate the gaussian random values
