Under the hood

How it works

01

Description

Turn a bundled image into a rotating 3D field of coloured cuboids.

02

Logic used

Each tile samples the image colour and brightness at its position. Brightness affects the tile depth and size; the slider changes the number of samples across the image.

03

Functions used

rotateY( ) - library function to rotate object around the Y axis

map( ) - to map values of a particular variable from one interval to another
