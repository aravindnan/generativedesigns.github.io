Under the hood

How it works

01

Description

Follow facial feature points detected in a live camera feed.

02

Logic used

clmtrackr estimates facial landmarks from the camera image. Lines are drawn from the canvas edges toward the detected points.

03

Functions used

tracker( ) - clm library function to create an object of clm

getCurrentPosition( ) - to obtain the coordinates of the face

line( ) - to draw lines between 2 points
