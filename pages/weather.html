Under the hood

How it works

01

Description

Search for a city to display its current conditions, temperature, humidity, precipitation, wind and pressure.

02

Logic used

The city name is sent to the weather service as a JSON request. The returned location and current-condition fields are drawn with labels and icons.

03

Functions used

loadJSON( ) - to make an API request call to the server hosting the weather data

select( ) - to access the DOM element in the HTML page directly.
