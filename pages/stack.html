Try it: Choose Push or press A to add an element; choose Pop or press D to remove the top element.

Under the hood

How it works

01

Description

A 3D stack demonstrates last-in, first-out behaviour as elements are pushed on and popped off.

02

Logic used

Press A to push a random value onto the array and D to remove its top value. The stack is redrawn as cuboids; attempts beyond its limit show overflow or underflow.

03

Functions used

pushStack( ) and popStack( ) handle both the on-screen buttons and keyboard input.

box( ) - library function to display a cuboid in a particular locaiton
