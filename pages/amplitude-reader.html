Under the hood

How it works

01

Description

Speak, whistle or make another sound and watch the polygon respond to changes in loudness.

02

Logic used

The microphone input is measured for amplitude continuously. That level is mapped to the polygon radius and scale.

03

Functions used

getLevel( ) - Library function to obtain the amplitude of user input

poly( ) - To draw a polygon of given radius and number of sides
