Under the hood

How it works

01

Description

Explore an animated grid of Perlin-noise line marks, with adjustable density from 3 × 3 to 50 × 50.

02

Logic used

Noise values vary smoothly across the grid and over time. The sketch maps each value to a line angle and stroke weight. The slider sets the same number of rows and columns, controlling the total number of marks.

03

Functions used

strokeWeight( ) Sets each line's width from its noise value.

noise( ) Samples a smooth two-dimensional noise field.
