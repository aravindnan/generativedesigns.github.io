How it works

01

Description

A nine-note synthesizer laid out as a three-by-three grid. Press a pad and it fills in, ripples outward and plays its note. Let go and it leaves a faint echo behind.

02

Logic used

Each pad is tied to a note. Pointer events (touch, mouse and pen) and the number keys all feed the same code, which starts the note while a pad is held and releases it afterwards. Every pad eases toward its pressed or resting state each frame, which gives the soft motion.

03

Functions used

addEventListener( )

Listens for pointer and keyboard input from the user.

MonoSynth( )

Library function that produces a musical note; triggerAttack( ) starts it and triggerRelease( ) ends it.
