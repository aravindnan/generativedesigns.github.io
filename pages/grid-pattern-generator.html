Grid Pattern

A grid of tiles that keep deciding, at random, which of them should light up.

System randomness p5.js Live
6 × 6Tiles
0.4Highlight chance per tile
2Library functions
Under the hood

How it works

01

Description

A 6 × 6 square grid that redraws itself on every frame. Each tile has a random chance of being highlighted, so the pattern is never the same twice.

02

Logic used

Every tile is drawn separately on each frame. A tile has a 0.4 chance of being highlighted, which is done by drawing a second, smaller square at the same centre with a reduced size.

03

Functions used

random( )

Library function that returns a random number between 0 and 1.

rect( )

Library function that draws a rectangle at a given position with given dimensions.
