Under the hood

How it works

01

Description

Watch a generated array of bars move into order as bubble sort compares neighbouring values.

02

Logic used

Each sorting step compares adjacent array values and swaps them when they are out of order. The bars are redrawn to show the progress.

03

Functions used

bsort( ) - to implement the bubble sort algorithm in the array

printsort( ) - to print the semi-sorted array at each frame

makearray( ) - to create a random array of elements
