Under the hood

How it works

01

Description

Choose between 3 and 50 moving nodes and watch them form temporary connections as they travel around a bounded field.

02

Logic used

The selected number of nodes move with small velocities and bounce off the canvas edges. Nodes within 200 pixels of one another are connected by lines.

03

Functions used

update( ) - to periodically change the position of each node

getDistance( ) - to calculate the distance between each node

draw( ) - to display each node in each frame
