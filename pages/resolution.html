Under the hood

How it works

01

Description

Rebuild a bundled photograph from coloured blocks and adjust the block size to change its level of detail.

02

Logic used

The sketch samples one colour from the image at each block interval, then draws a square of that colour. The slider changes the sampling interval.

03

Functions used

imageReso( ) - To draw rectangles on the canvas by taking color values from the image

loadImage( ) - to load an image into the system memory
