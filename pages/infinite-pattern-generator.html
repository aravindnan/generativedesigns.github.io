Under the hood

How it works

01

Description

Floral patterns that are generated endlessly and never repeat. Each pattern is randomised by the number of sides of its polygons, the radius of its shapes and the colours used.

02

Logic used

Every frame prints a different combination of elements, at a frame rate of 1. Each group of elements is drawn by its own function with suitable arguments.

03

Functions used

poly( )

User-defined function that draws a polygon with N sides.

pointOnCircle( )

Calculates the coordinates of a point on a given circle.

getRandomFromPalette( )

Selects a colour from the sketch's palette.

randomSelectTwo( )

Chooses between two alternatives using a random value.
