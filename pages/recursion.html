Under the hood

How it works

01

Description

A branching tree grows through repeated calls to the same drawing function. Adjust the branch angle from 10° to 80° to explore different forms.

02

Logic used

Each call draws a branch and recursively creates smaller branches from its end. The slider controls the angle between the left and right branches.

03

Functions used

translate( ) - to move the position of the origin to the next branch

branchup( ) - the recursive function that is being called on each frame
